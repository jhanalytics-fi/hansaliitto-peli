# Hansaliitto - pelitesti

Anno 1422. Turkulaiset kauppiassuvut käyvät kauppaa Itämerellä ja Pohjanmerellä. Tämä on lautapelin digitaalinen
pelitestiversio: avaa `index.html` selaimessa tai pelaa GitHub Pagesissa. Hotseat 2-4 pelaajaa samalla laitteella.

Versio v0.3: historiallinen kauppakartta ja etäisyyspohjaiset hinnat (v3), liikkuminen, kaupankäynti, Turun pankki, velka, hintataulukko. Tapahtumakortit puuttuvat vielä.
